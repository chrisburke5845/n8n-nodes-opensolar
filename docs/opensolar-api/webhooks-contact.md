# Contact

A Contact payload contains details about contacts related to a project.

## Example

```
{
  "timestamp": "1605832666",
  "model": "Contact",
  "model_id": 5,
  "identifier": "6ab6a60d-1a4d-4374-88af-92f7c02e3223",
  "event": "UPDATE",
  "event_id": 1,
  "fields": {
    "display": "george costanza",
    "email": "george@vanderlayindustries.com",
    "family_name": "costanza",
    "first_name": "george",
    "id": 5,
    "org": "/api/orgs/14/",
    "phone": "99991234",
    "projects": ["/api/orgs/14/projects/10/"],
    "url": "/api/orgs/14/contacts/5/",
    "user": "/auth/users/6/"
  }
}
```
