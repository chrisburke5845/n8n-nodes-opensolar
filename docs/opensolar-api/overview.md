# Overview

## Introduction

Welcome to the OpenSolar API! You can use our API to access OpenSolar API data and services subject to the [OpenSolar Terms & Conditions](https://www.opensolar.com/content/legal). For a higher level (and non-technical) description of what the OpenSolar API is and what it can do, please visit the [OpenSolar API HelpCenter page](https://support.opensolar.com/hc/en-us/articles/4407230526745-Using-the-OpenSolar-API).

> **Info:**
>
> From **17 March, 2026** onwards, API access is restricted to organisations that have opted into a paid plan. Two plans are available:
>
> - **API Access** — Core API access; most endpoints behave the same. Some endpoints return reduced data (for example, System Details and the Project `design` field). See [API Access Plans](api-access-plans.md) for details.
> - **Raw Data API Access** — Full access including design-related data (e.g. full System Details response, compressed `design` on Projects).
>
> A **30-day free trial** is available for both plans; users can opt in to try API access before subscribing.
