# Project

A project payload contains details about the state of a project.

> **Note:**
>
> The URL for downloading private files ("file_contents") is time-delimited and will expire after 1 hour.

> **Note:**
>
> Payload data is subject to restrictions based on your organisation's API plan. The `design` field (compressed design data) is only included for organisations on **Raw Data API Access**. See [API Access Plans](api-access-plans.md) for details.
